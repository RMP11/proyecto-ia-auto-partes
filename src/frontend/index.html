Métrica Referencia Modelo

El sesgo representa la diferencia entre lo predicho y lo real (un valor positivo indica sobreestimación y uno negativo subestimación). Por su parte, el WAPE pondera el error frente al volumen total de ventas, por lo que su desempeño puede variar en productos de menor rotación.

Una mejora del promedio no implica mejorar todos los productos. Revisa cada fila.


El error de cada sucursal

Sucursal MAE referencia MAE modelo

El MAE mide el error absoluto medio de las predicciones. Un valor menor indica mayor precisión; compara la referencia con el modelo en cada sucursal.

El MAE refleja el error promedio del pronóstico, pero no garantiza la precisión de cada predicción. Un mejor desempeño predictivo no implica por sí solo ahorro, menos faltantes o menor desperdicio.
